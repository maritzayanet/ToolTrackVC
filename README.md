# ToolTrack

RESTful Web API for managing a tool inventory.

ToolTrack is a backend application developed with ASP.NET Core that provides
CRUD operations for managing tools in an inventory.

The project was created as a practical exercise to apply modern C#,
ASP.NET Core Web API, Entity Framework Core, SQL Server, REST principles,
DTOs, dependency injection, repository and service layers, validation,
logging, and global exception handling.

## Features

- Create, retrieve, update, and delete tools.
- Input validation using Data Annotations.
- DTOs to separate API contracts from database entities.
- Service and Repository layers.
- Entity Framework Core for data access.
- SQL Server database integration.
- Dependency Injection.
- Global exception handling.
- Standard HTTP status codes.
- Structured logging with `ILogger`.
- Swagger / OpenAPI documentation.
- Secure local configuration using .NET User Secrets.
